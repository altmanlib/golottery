# 后端 Roadmap

文档索引见 [README.md](README.md)

## 怎么用

- 本文件是本项目唯一登记待办与已知缺口的文档，其余文档只记录当前事实
- **开始工作前**先读本文件，从「计划中」中取最靠前、依赖已满足的一项
- **开工时**把条目移到「现在」
- **完成时**移到「已完成」并写上提交号；roadmap 的改动与对应工作放在同一个提交里，行为变化同时写回 [PRD.md](PRD.md) 或 [DESIGN.md](DESIGN.md)
- **发现新工作**登记到「之后」；属于 Web 或小程序的工作登记到对应项目的 roadmap
- 涉及 `api/openapi.yaml` 契约变更的条目，在「内容」里写明受影响的端
- 「现在」最多两项；条目状态以本文件为准
- 编号只增不复用：`API-` 作为编号前缀

## 状态判定

| 状态 | 标准 |
|---|---|
| 已完成 | 代码合入 `main`，且文档与现实一致 |
| 现在 | 方案已定稿或代码已开工，但尚未全量交付 |
| 计划中 | 已登记、依赖已满足，可被取用 |
| 之后 | 已发现，但依赖未满足或尚未排期 |
| 暂缓 | 已评估过，但当前不做；需记录触发条件，重新评估前不得开工 |
