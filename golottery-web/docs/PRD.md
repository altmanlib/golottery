# 管理端与大屏 · 产品需求

## 1. 目标与入口

Web 提供组织控制台、主持人大屏与平台运营后台。组织管理员配置活动并导出数据；主持人现场控制抽奖；平台运营开通组织和场次。宾客签到、现场工作人员审批在微信小程序内完成。

| 角色 | 入口 | 权限范围 |
| --- | --- | --- |
| 组织管理员 | Web 控制台 | 本组织所有活动 |
| 主持人 | 活动专属大屏链接 + host 凭证 | 当前活动的抽奖与展示 |
| 平台运营 | 运营后台 | 组织开通、配额和平台用量 |

## 2. 组织与活动（控制台）

| 编号 | 功能 | 要求 | 优先级 |
| --- | --- | --- | --- |
| O1 | 登录 | 邮箱 + 口令；组织由运营开通，不提供自助注册 | P0 |
| O2 | 配额展示 | 显示已开通、已使用和剩余场次；不足时提示联系开通 | P0 |
| O3 | 活动配置 | 创建/编辑名称、签到时间窗、是否允许兼中 | P0 |
| O4 | 活动码 | 生成并下载活动小程序码与短链 | P0 |
| O5 | 成员管理 | 邀请组织管理员、为活动配置现场工作人员 | P1 |
| O6 | 复制模板 | 复制奖项与围栏，不复制名单和中奖数据 | P1 |
| O7 | 品牌配置 | 活动显示名、封面、大屏主题色 | P2 |

创建活动消耗一场次；单场名单人数受套餐上限约束。管理员仅能看到本组织数据。

## 3. 活动配置与数据

| 编号 | 功能 | 要求 | 优先级 |
| --- | --- | --- | --- |
| B1 | 名单导入 | 上传 Excel；展示重复与格式错误及导入结果 | P0 |
| B2 | 围栏与时间窗 | 设置 GCJ-02 中心点、半径及签到起止时间；半径默认 400 米，可设 100～1000 米 | P0 |
| B3 | 奖项配置 | 名称、奖品、人数、顺序；兼中开关位于活动级 | P0 |
| B4 | 数据导出 | 导出签到名单与中奖名单 Excel | P0 |
| B5 | 抽奖日志 | 查看每次抽取时间、奖项、结果及作废状态 | P1 |
| B6 | 活动结束 | 结束活动；位置数据按后端保留策略清理 | P1 |

签到尝试明细含坐标、精度和距离，仅组织管理员可导出；导出结果中标注人工确认方式和操作人。

## 4. 签到大屏与抽奖

| 编号 | 功能 | 要求 | 优先级 |
| --- | --- | --- | --- |
| D1 | 签到大屏 | 展示活动码和实时签到人数 | P0 |
| D2 | 抽奖控制 | 选择奖项、开始/停止，支持键盘快捷键 | P0 |
| D3 | 动画与结果 | 姓名滚动后展示服务端结果、姓名和部门；动画不决定结果 | P0 |
| D4 | 缺席重抽 | 作废中奖结果并补抽，作废记录保留 | P0 |
| D5 | 多人抽取 | 一次抽多人，结果分页展示 | P1 |
| D6 | 名单总览 | 按奖项展示有效中奖者 | P1 |
| D7 | 网络异常 | 显著提示断网，恢复后重连并同步最新状态 | P1 |

抽奖仅从已签到人员中选取；默认一人一奖，活动可配置兼中。结果由服务端随机抽取并先落库后展示；刷新后恢复当前状态。大屏面向最新 Chrome / Edge，按 1920×1080 设计；主持人应使用独立稳定网络。

## 5. 平台运营与边界

| 编号 | 功能 | 要求 | 优先级 |
| --- | --- | --- | --- |
| P1 | 组织开通 | 创建组织并授予场次配额和人数档位 | P0 |
| P2 | 用量 | 查看组织数、活动数、峰值签到等基础指标 | P1 |
| P3 | 支付与发票 | 在线购买场次和开票 | P2 |

Web 不执行围栏判定与随机抽取；接口鉴权、租户隔离和抽奖事务由后端负责。首发不做复杂在线计费或自动开票
